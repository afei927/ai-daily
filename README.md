# AI Daily

每天自动收集热度最高的 **AI Agent 工具、Skills、MCP Server** 信息。

- 每日 UTC 2:00（北京时间 10:00）自动更新
- 数据按日期归档在 `daily/` 目录

## 数据源

| 来源 | 内容 |
|------|------|
| [Smithery.ai](https://smithery.ai) | Trending MCP Servers |
| [MCP.so](https://mcp.so) | 新上架 MCP Servers & Skills |
| [GitHub Topics](https://github.com/topics/ai-agent) | AI Agent 高星项目 |
| [GitHub Topics](https://github.com/topics/mcp-server) | MCP Server 高星项目 |

## 手动触发

在 GitHub Actions 页面点击 `Run workflow` 即可立即更新。
